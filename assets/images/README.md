# Images Folder

Add your portfolio images here:

## Folder Structure:
- `photography/` - Your commercial photography work
- `data-science/` - Data visualizations and project screenshots  
- `creative/` - Creative projects and collaborations
- `editorial/` - Varsity Newspaper and editorial work

## Image Guidelines:
- Use high-quality images (minimum 800px width)
- Keep file sizes under 500KB for web optimization
- Use descriptive filenames (e.g., `vans-campaign-2024.jpg`)
- Include both landscape and portrait orientations

## Supported Formats:
- JPG/JPEG (recommended for photos)
- PNG (for graphics with transparency)
- WebP (modern format, smaller file sizes)

## Quick Start:
1. Add your best images to the appropriate folders
2. Update the HTML to reference your images
3. Test the website to ensure images load properly
