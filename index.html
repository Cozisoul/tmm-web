TMM–OS

Design System Architecture

Personal operating system and comprehensive design system architecture. A framework bridging systematic engineering principles with poetic creative expression. Currently developing v5.0 with modular CSS components and responsive design patterns that embody the "Systematic-Poetic" philosophy.

Systematic Foundation

12-column grid system, 8px spacing scale, functional color tokens, and modular component architecture inspired by Konstantin Grcic and Dieter Rams.

Poetic Expression

Intentional asymmetry, fluid animations, and narrative-driven design patterns inspired by Mark Bradford, Carrie Mae Weems, and Virgil Abloh.

Dual-Voice Typography

Systematic voice (monospace) for annotations and metadata, Poetic voice (serif/sans-serif) for narrative content, and Signature voice for personal expression.
